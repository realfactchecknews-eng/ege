# ЕГЭ-Хаб · Русский + English · НИУ ВШЭ

**Живой сайт:** https://realfactchecknews-eng.github.io/ege/

Объединённый хаб подготовки к ЕГЭ по русскому языку и английскому языку. Цель — 90+ баллов и поступление в НИУ ВШЭ.

---

## Разделы

### 🇷🇺 Русский язык (`/russian/`)
- **27 заданий** с теорией и практикой (5+ примеров на каждое задание, автопроверка)
- **Тренажёр ударений** — 80+ слов из орфоэпического минимума ФИПИ
- **Паронимы** — список ФИПИ + мини-тренажёр
- **Шаблон сочинения** (задание 27) с клише для каждой части
- **Домашние задания** по темам с прогрессом в localStorage
- **Проверенные источники** — ФИПИ, Решу ЕГЭ, НИУ ВШЭ

### 🇬🇧 English (`/english/`)
- **Listening** (Tasks 1–9) — стратегии + практика True/False/Not Stated
- **Reading** (Tasks 10–11) — gap-filling + heading matching с разбором
- **Grammar** (Tasks 12–18) — 15 примеров, все времена, пассив, условные
- **Word Formation** (Tasks 19–25) — 15 примеров, все суффиксы и приставки
- **Vocabulary** (Tasks 26–31) — 15 примеров, collocations, phrasal verbs
- **Writing** (Tasks 37–38) — шаблоны email и opinion essay, фразы
- **Speaking** (Tasks 1–4) — стратегии и фразы для всех 4 заданий
- **Irregular Verbs** — тренажёр по 60 неправильным глаголам
- **Homework** — задания по секциям с прогрессом

---

## Технологии

- Чистый HTML/CSS/JS (без сборщиков и фреймворков)
- SPA с hash-routing
- Данные в отдельных JS-файлах
- Прогресс в `localStorage`
- Адаптивный дизайн (mobile-first)
- Хостинг: GitHub Pages
